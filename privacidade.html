Política de privacidade – Hermes Calendar/Tasks

Última atualização: 8 de novembro de 2026.

Finalidade

Hermes Calendar/Tasks é uma aplicação de uso exclusivamente pessoal. Ela permite que um assistente de IA (Hermes Agent), executado em um servidor do próprio autor, acesse a conta Google do próprio autor para executar comandos dados por ele. A aplicação não é destinada a outros usuários.

Dados acessados

Com a autorização do titular da conta, a aplicação pode acessar dados do Google Agenda, Gmail, Google Drive, Google Contatos, Google Planilhas e Google Documentos, conforme as permissões concedidas na tela de consentimento do Google.

Uso dos dados

  • Os dados são usados apenas para executar as solicitações feitas pelo próprio titular da conta (por exemplo, criar ou consultar eventos na agenda).
  • Os tokens de acesso e os dados obtidos ficam armazenados no dispositivo do próprio autor.
  • Para interpretar e executar os comandos, trechos do conteúdo podem ser enviados aos provedores de modelos de IA escolhidos pelo próprio titular (por exemplo, OpenRouter), sujeitos às políticas desses provedores.

Compartilhamento

Os dados não são vendidos, cedidos nem compartilhados com terceiros para publicidade ou qualquer outra finalidade, além do processamento descrito acima.

Conformidade com as políticas do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação do acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
